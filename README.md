# Mayhem Coach Fitness

I need to create a tool for excercising based in the Mayhem Athlete program. For 30 minute, 60 and 90 workouts. Allow user to choose body type, how they want to progress, what they want to build, what body type theyre looking for, etc. conbination of Freeletics and Mayhem Athlete with a functional fitness base. Also to program the week in what days theyll be training and what muscle groups theyll be targeting for each day. Program should act as a coach and ask how their day is looking, how much energy, rest, sleep, etc. to build a data base of insights.
